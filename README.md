# fromis_9 · chart journey

프로미스나인의 **실물 앨범 수록곡만** 발매순으로 따라 치며 초동 판매량 차트를 완주하는 팬메이드 게임입니다. 디지털 싱글·OST·프로젝트·방송 경연곡은 코스에서 제외합니다.

## 실행

Node.js 22 이상, 의존성 설치 없이 실행합니다.

```sh
node dev.mjs
```

브라우저에서 http://127.0.0.1:4178 을 엽니다. 배포 파일은 `dist/`입니다.

## 플레이

- 메인 화면의 게임 시작을 누르면 3·2·1 카운트다운 뒤 게임 화면에서 시작합니다. 카운트다운 중 입력은 기록되지 않으며, 취소하거나 탭을 떠나면 메인으로 돌아갑니다.
- 위쪽 차트는 앨범 발매순·초동 판매량을 보여주고, 아래쪽의 작은 입력칸은 고정됩니다.
- 입력한 정답의 진행률에 따라 재킷이 앨범의 초동 지점을 잇는 선 위로 이동합니다. 중간 위치는 게임 진행을 나타내며 일별 판매량 데이터가 아닙니다.
- 입력을 멈추면 진행점도 멈춥니다. 오타를 지워도 차트를 거꾸로 이동하지 않습니다.
- `전체 차트`와 `따라가기`로 전체 기록 또는 현재 주변 앨범을 볼 수 있습니다. 따라가기는 주변 판매량의 최솟값~최댓값을 세로로 확대하고 실제 눈금을 표시합니다. 축은 앨범이 바뀔 때 갱신하며 전체 보기는 0에서 시작합니다.
- 제목을 완성하면 Enter 없이 다음 곡으로 이동합니다. 한글 마지막 글자가 조합 중인 상태에서 정답이 되면 자동 확정하고, 남은 IME 이벤트가 새 곡에 섞이지 않도록 처리합니다. 영문 대소문자를 구분하지 않습니다.
- Esc 또는 일시정지 버튼으로 시간을 멈춥니다. 탭을 떠나거나 앨범·출처 목록을 열어도 일시정지합니다.
- 타수는 두벌식 한글 자모 입력 수 기준입니다. 정확도는 입력 시도 중 올바른 자모 비율이며, 최고 기록은 브라우저에 저장됩니다.

## 곡과 초동 데이터

- `dist/data/album-course.json`: 실물 14앨범, 고유 67곡, 포함·제외 근거.
- `dist/data/first-week-sales.json`: 초동 보도 수치·집계 기간·출처. 비공식 집계 3건은 별도 표시하고 근사치는 화면의 `약`으로 구분합니다.
- `README-albums.md`, `README-sales.md`: 검증 과정·자료 한계·버전 처리 설명.
- `dist/data/discography.json`, `README-catalog.md`: 이전 전체 발매 카탈로그의 참조 자료이며 현재 게임은 이를 사용하지 않습니다.

Talk & Talk 11,137장, Glow ME 107,489장, 일본 EP 19,511장은 사용자 선택에 따라 비공식 정리 자료를 채택했습니다. 일본 EP는 오리콘 첫 주이며 국내 발매 첫 7일과 집계 기간·기관이 다릅니다. 차트와 앨범·출처에 이를 표시합니다. 디지털 선공개 뒤 실물에 수록된 유리구두는 To. Heart의 실제 수록 위치에서 한 번 포함합니다. 사용자 지정 제목 15개는 게임용 표기를 사용하고 원제와 별칭을 보존합니다.

## 구성과 검증

- `core.mjs`: 한글 IME·입력·기록 엔진
- `input-controller.mjs`: 한글 자동 확정과 브라우저 IME 이벤트 처리
- `countdown.mjs`: 취소 가능한 시작 카운트다운
- `chart-progress.mjs`: 곡 진행과 앨범 차트 위치의 매핑
- `chart-view.mjs`, `chart-axis.mjs`: 반응형 SVG 차트와 확대 축
- `app.mjs`, `chart.css`: 게임과 모바일 입력 영역

```sh
node --test --test-isolation=none
node scripts/check-chart-data.mjs
```

노래와 앨범 재킷의 권리는 각 권리자에게 있습니다. 비공식 팬 프로젝트입니다.
