# fromis_9 · chart journey

프로미스나인의 **실물 앨범 수록곡만** 발매순으로 따라 치며 초동 판매량 차트를 완주하는 팬메이드 게임입니다. 디지털 싱글·OST·프로젝트·방송 경연곡은 코스에서 제외합니다.

## 실행

Node.js 22 이상, 의존성 설치 없이 실행합니다.

```sh
node dev.mjs
```

브라우저에서 http://127.0.0.1:4178 을 엽니다. 배포 파일은 `dist/`입니다.

## 플레이

- 위쪽 차트는 앨범 발매순·초동 판매량을 보여주고, 아래쪽의 작은 입력칸은 고정됩니다.
- 입력한 정답의 진행률에 따라 재킷이 앨범의 초동 지점을 잇는 선 위로 이동합니다. 중간 위치는 게임 진행을 나타내며 일별 판매량 데이터가 아닙니다.
- 입력을 멈추면 진행점도 멈춥니다. 오타를 지워도 차트를 거꾸로 이동하지 않습니다.
- `전체 차트`와 `따라가기`로 전체 기록 또는 현재 주변 앨범을 볼 수 있습니다. 따라가기의 세로축은 주변 앨범의 수치에 맞춰 표시되며, 전체 보기는 공통 축으로 비교합니다.
- 제목을 완성하면 다음 곡으로 이동합니다. 영문 대소문자를 구분하지 않고, 한글 IME 조합 중인 마지막 글자는 Enter로 확정합니다.
- Esc 또는 일시정지 버튼으로 시간을 멈춥니다. 탭을 떠나거나 앨범·출처 목록을 열어도 일시정지합니다.
- 타수는 두벌식 한글 자모 입력 수 기준입니다. 정확도는 입력 시도 중 올바른 자모 비율이며, 최고 기록은 브라우저에 저장됩니다.

## 곡과 초동 데이터

- `dist/data/album-course.json`: 실물 14앨범, 고유 67곡, 포함·제외 근거.
- `dist/data/first-week-sales.json`: 초동 보도 수치·집계 기간·출처. 확인 불가 값은 null, 근사치는 `approximate:true`와 화면의 `약` 표시로 구분합니다.
- `README-albums.md`, `README-sales.md`: 검증 과정·자료 한계·버전 처리 설명.
- `dist/data/discography.json`, `README-catalog.md`: 이전 전체 발매 카탈로그의 참조 자료이며 현재 게임은 이를 사용하지 않습니다.

일본 EP 등 초동 근거가 확인되지 않은 앨범도 수록곡은 플레이할 수 있습니다. 해당 앨범은 그래프에 수치 지점을 그리지 않으며 0장으로 간주하지 않습니다. 디지털 선공개 뒤 실물에 수록된 유리구두는 To. Heart의 실제 수록 위치에서 한 번 포함합니다.

## 구성과 검증

- `core.mjs`: 한글 IME·입력·기록 엔진
- `chart-progress.mjs`: 곡 진행과 앨범 차트 위치의 매핑
- `chart-view.mjs`: 반응형 SVG 차트
- `app.mjs`, `chart.css`: 게임과 모바일 입력 영역

```sh
node --test --test-isolation=none tests/core.test.mjs tests/chart-progress.test.mjs
node scripts/check-chart-data.mjs
```

노래와 앨범 재킷의 권리는 각 권리자에게 있습니다. 비공식 팬 프로젝트입니다.
