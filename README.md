# fromis_9 · chart journey

프로미스나인의 **실물 앨범 수록곡만** 발매순으로 따라 치며 초동 판매량 차트를 완주하는 팬메이드 게임입니다. 디지털 싱글·OST·프로젝트·방송 경연곡은 코스에서 제외합니다.

## 실행

Node.js 22 이상, 의존성 설치 없이 실행합니다.

```sh
node dev.mjs
```

브라우저에서 http://127.0.0.1:4178 을 엽니다. 배포 파일은 `dist/`입니다.

## 플레이

- 메인 화면의 게임 시작을 누르면 3·2·1 카운트다운 뒤 게임 화면에서 시작합니다. 카운트다운 중 입력은 기록되지 않으며, 취소하거나 탭을 떠나면 메인으로 돌아갑니다.
- 메인에서 닉네임과 플레이할 앨범을 고릅니다. 일부 앨범을 고르면 발매순 연습 코스로 진행하며 개인 기록에만 저장합니다. 전체 14앨범을 고른 완주만 온라인 랭킹 제출 대상입니다.
- 위쪽 차트는 앨범 발매순·초동 판매량을 보여주고, 아래쪽의 작은 입력칸은 고정됩니다.
- 재킷은 가상 시작점 0에서 출발합니다. 현재 앨범의 곡을 모두 치면 해당 앨범의 초동 점에 도착하며, 이후 이전 완료 앨범 점에서 현재 앨범 점으로 이동합니다. 마지막 앨범 점에 도착하면 완주합니다. 중간 높이는 게임 진행이며 판매량 관측이 아닙니다.
- 입력을 멈추면 진행점도 멈춥니다. 오타를 지워도 차트를 거꾸로 이동하지 않습니다.
- `전체 차트`와 `따라가기`로 전체 기록 또는 현재 주변 앨범을 볼 수 있습니다. 따라가기는 주변 판매량의 최솟값~최댓값을 세로로 확대하고 실제 눈금을 표시합니다. 축은 앨범이 바뀔 때 갱신하며 전체 보기는 0에서 시작합니다.
- 제목을 완성하면 Enter 없이 다음 곡으로 이동합니다. 한글 마지막 글자가 조합 중인 상태에서 정답이 되면 자동 확정하고, 남은 IME 이벤트가 새 곡에 섞이지 않도록 처리합니다. 영문 대소문자를 구분하지 않습니다.
- IME의 늦은 확정은 곡 경계 단위로 걸러냅니다. 한영 전환이나 대기 시간으로 보호를 해제하지 않고, 이전 음절과 영문 첫 글자가 합쳐진 경우 영문 입력을 보존합니다. 카운트다운 중 시작한 조합은 종료가 늦게 도착해도 기록하지 않습니다.
- 카운트다운이 끝난 뒤부터 완주까지 시간이 계속 흐릅니다. 일시정지 버튼과 단축키는 없으며, 탭을 떠나거나 앨범·출처 목록을 열어도 시간이 계산됩니다.
- 타수는 두벌식 한글 자모 입력 수 기준입니다. 정확도는 입력 시도 중 올바른 자모 비율이며, 개인 기록은 브라우저에 코스·기기별로 저장됩니다. 기존 전체 코스 최고 기록도 보존합니다.

## 닉네임과 온라인 랭킹

메인의 주간(최근 7일)·전체 랭킹은 온라인에서 PC/모바일별, 닉네임별 최고 기록을 조회합니다. 개인 기록 탭과 상단 개인 최고·완주 횟수는 이 브라우저의 로컬 기록만 사용하며 서버 개인 기록을 조회하거나 합치지 않습니다. 로컬 기록은 닉네임·코스·기기별로 구분하고 다른 브라우저나 기기와 공유하지 않습니다. 브라우저 데이터를 지우면 로컬 기록도 사라집니다. Supabase Auth와 익명 로그인은 사용하지 않습니다.

닉네임은 꼬박게임과 같은 초성·숫자·ASCII 특수기호만 1~6글자 허용합니다. 영문, 완성형 한글, 모음, 공백, 이모지는 사용할 수 없습니다. 입력한 닉네임은 변경하거나 게임을 시작할 때 이 기기에 자동으로 기억하며, 별도 저장 버튼이나 서버 닉네임 등록은 없습니다. 이전 규칙의 닉네임과 기록은 삭제하거나 자동 변환하지 않습니다.

기존 꼬박게임 Supabase 프로젝트의 공개 연결 정보가 설정돼 있습니다. **갱신한 `supabase/schema.sql` 전체를 기존 프로젝트 SQL Editor에서 실행**하면 완주 기록 전용 테이블 하나로 전환됩니다. 기존 완주 기록과 ID는 유지하고 미완주 행, 별도 닉네임·코스 테이블, 사용하지 않는 컬럼을 제거합니다. 기록 테이블은 `id`, `nickname`, `device`, `finished_at`, `elapsed_ms`, `cpm`, `accuracy`의 7개 컬럼입니다. Auth 설정과 꼬박게임 객체는 변경하지 않습니다. `supabase/README.md`에 전환 순서와 기존 기록 보존 범위가 있습니다.

게임 시작 단계에서는 서버 기록을 생성하지 않고, 전체 코스를 완주했을 때 한 번 제출합니다. 완주 기록의 UUID로 같은 결과를 재시도해도 중복 저장되지 않으며 기존 결과를 수정하지 않습니다. 연결 실패가 게임 진행이나 개인 기록 저장을 막지는 않습니다. 일부 앨범 코스는 클라이언트에서 제출하지 않으며 서버 함수도 전체 앨범 ID·순서·완료 개수·시간·입력 통계를 검증합니다. 코스 버전 구분과 서버 시작 시각 비교는 사용하지 않습니다.

개인 기록의 로컬 전환은 화면 변경만으로 동작합니다. 기존 서버의 온라인 개인 조회 함수까지 제거하려면 `supabase/disable-online-personal.sql`을 실행합니다. 완주 데이터와 주간·전체 랭킹은 유지됩니다.

## 소스 공개와 기록 데이터

`dist/data/ranking-config.json`의 Supabase 주소와 publishable 키는 브라우저용 공개 연결 정보입니다. 관리자 비밀키는 넣지 않습니다. `.gitignore`는 환경 파일·로그·의존성·압축 산출물을 제외합니다. Sites 배포 설정인 `.openai/hosting.json`은 공개 키나 비밀키를 담지 않습니다.

온라인 랭킹에는 전체 완주 시 닉네임·기기 분류·기록 시간·타수·정확도와 기록 ID·서버 완주 시각이 저장됩니다. 랭킹 조회 요청에는 닉네임을 보내지 않으며 내 순위 강조는 브라우저에서 처리합니다. 개인 기록과 닉네임 설정은 브라우저 저장소에 보관합니다. 이름·연락처·위치·로그인 정보는 게임에서 요구하지 않습니다. Git 커밋 작성자 이름과 이메일은 Git 이력의 별도 메타데이터이므로 소스 파일과 함께 공개 범위를 확인해야 합니다.

## 곡과 초동 데이터

- `dist/data/album-course.json`: 실물 14앨범, 고유 67곡, 포함·제외 근거.
- `dist/data/first-week-sales.json`: 초동 보도 수치·집계 기간·출처. 비공식 집계 3건은 별도 표시하고 근사치는 화면의 `약`으로 구분합니다.
- `README-albums.md`, `README-sales.md`: 검증 과정·자료 한계·버전 처리 설명.
- `dist/data/discography.json`, `README-catalog.md`: 이전 전체 발매 카탈로그의 참조 자료이며 현재 게임은 이를 사용하지 않습니다.

Talk & Talk 11,137장, Glow ME 107,489장, 일본 EP 19,511장은 사용자 선택에 따라 비공식 정리 자료를 채택했습니다. 일본 EP는 오리콘 첫 주이며 국내 발매 첫 7일과 집계 기간·기관이 다릅니다. 차트와 앨범·출처에 이를 표시합니다. 디지털 선공개 뒤 실물에 수록된 유리구두는 To. Heart의 실제 수록 위치에서 한 번 포함합니다. 사용자 지정 제목 15개는 게임용 표기를 사용하고 원제와 별칭을 보존합니다.

## 구성과 검증

- `core.mjs`: 한글 IME·입력·기록 엔진
- `input-controller.mjs`: 한글 자동 확정과 브라우저 IME 이벤트 처리
- `countdown.mjs`: 취소 가능한 시작 카운트다운
- `chart-progress.mjs`: 곡 진행과 앨범 차트 위치의 매핑
- `chart-view.mjs`, `chart-axis.mjs`: 반응형 SVG 차트와 확대 축
- `course-selection.mjs`: 앨범 선택·전체 코스 여부·입력 규칙 해시
- `personal-records.mjs`, `home-records.mjs`: 기기별 개인 기록과 메인 기록 탭
- `ranking-client.mjs`, `supabase/schema.sql`: Supabase 닉네임 랭킹·전체 코스 서버 검증
- `app.mjs`, `chart.css`: 게임과 모바일 입력 영역

```sh
node --test --test-isolation=none
node scripts/check-chart-data.mjs
```

노래와 앨범 재킷의 권리는 각 권리자에게 있습니다. 비공식 팬 프로젝트입니다.
