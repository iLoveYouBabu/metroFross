# fromis_9 · typing journey

프로미스나인의 정식 그룹 명의 곡 제목을 발매일과 트랙 순으로 따라 치며 완주하는 팬메이드 게임입니다.

## 실행

Node.js 22 이상에서 의존성 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 http://127.0.0.1:4178 을 엽니다. 배포용 정적 파일은 `dist/`에 있습니다.

## 플레이

- 보이는 제목을 입력하면 타이머가 시작됩니다. 영문 대소문자를 구분하지 않습니다.
- 정답이 완성되면 다음 곡으로 이동합니다. 한글 IME 조합 중인 마지막 글자는 Enter로 확정합니다.
- 오타는 고쳐서 진행합니다. Esc 또는 일시정지 버튼으로 시간을 멈출 수 있습니다.
- 곡 목록을 열거나 탭을 떠나면 일시정지합니다.
- 타수는 영문·기호 1타, 한글은 두벌식 자모 입력 수 기준입니다. 정확도는 입력 시도 중 맞게 친 자모 비율입니다.
- 완주 시간·평균 타수·정확도와 최고 완주 기록을 브라우저에 저장합니다.
- 붙여넣기는 기록에 사용하지 않습니다.

## 구성

- `dist/data/discography.json`: 곡·앨범·발매일·근거 자료
- `dist/core.mjs`: 화면과 독립된 입력·기록 엔진
- `dist/app.mjs`: 입력·앨범 표시·완주 화면
- `dist/style.css`: 고정된 타이핑 레이아웃
- `README-catalog.md`, `assets-manifest.json`: 수록 범위와 재킷 출처

메트로 형식 등 다른 진행 화면으로 바꾸더라도 같은 곡 목록과 입력 엔진을 사용할 수 있도록 분리했습니다.

## 확인

```sh
npm test
npm run check
```
